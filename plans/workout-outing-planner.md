# Workout Outing Planner

Use this before an activity, class, gym visit, or trainer appointment. The goal is to place the **whole outing** on the calendar and learn the real timing after a few visits.

## 1. Define the outing

| Item | Plan |
|---|---|
| Activity |  |

| Date |  |
| Activity start and end |  |
| Booking or cancellation deadline |  |
| Companion, class, or trainer |  |
| Starting location |  |
| Next destination |  |
| Full / short / minimum version |  |

## 2. Calculate the full calendar block

Use the rows that apply. Do not count the warm-up twice if it is already part of a class or appointment.

| Segment | Estimated minutes | Actual minutes |
|---|---:|---:|
| Prepare and pack |  |  |
| Travel to venue |  |  |
| Find parking, walk, or lock bike |  |  |
| Check in, use locker, and change |  |  |
| First-visit or arrival buffer |  |  |
| Activity, including any built-in warm-up/cool-down |  |  |
| Shower, dress, and gather belongings |  |  |
| Travel home or to next destination |  |  |
| Park, enter, and unpack at destination |  |  |
| Other known transition |  |  |
| **Total calendar block** | **0** | **0** |

Formula:

> **Calendar block = every applicable segment above, from the moment preparation begins until arrival and unpacking at the next destination.**

Then plan backward:

> **Start preparing = fixed activity start time − all pre-activity segments.**

## Worked example

A 45-minute class at 6:00 p.m. can occupy a 2-hour-20-minute calendar block:

| Time | Segment | Minutes |
|---|---|---:|
| 5:10–5:20 | Prepare and pack | 10 |
| 5:20–5:40 | Drive | 20 |
| 5:40–5:50 | Park and walk | 10 |
| 5:50–6:00 | Check in, change, and arrive early | 10 |
| 6:00–6:45 | Class | 45 |
| 6:45–7:05 | Shower and dress | 20 |
| 7:05–7:25 | Drive home | 20 |
| 7:25–7:30 | Unload and put things away | 5 |
|  | **Total** | **140 minutes** |

The useful calendar entry is **5:10–7:30 p.m.**, with the class details inside it. These are example assumptions; the participant replaces them with actual times after each visit.

## 3. Plan backward checklist

- Confirm the booking and cancellation policy.
- Check the route at the time of day you will travel.
- Identify the parking structure, entrance, and walking route.
- Check whether the venue provides lockers, towels, mats, or showers.
- Decide whether you will arrive dressed or change there.
- Decide what happens immediately afterward.
- Add a larger buffer for the first visit; revise it after learning the venue.
- Put preparation and travel on the calendar, not only the class.

## 4. Pack for this outing

Start with the venue's actual requirements.

- Activity clothing and appropriate shoes
- Water bottle or confirmed water access
- Phone, ID, membership or booking details, and payment method if needed
- Lock if the venue requires one
- Any activity-specific safety equipment
- Towel, shower shoes, toiletries, clean underwear, and next-destination clothing if changing there
- Hair, skin, menstrual, or other personal-care items needed afterward
- Medication or emergency item normally carried as directed
- Food or snack only if timing and the participant's plan call for it
- Bag for wet or used clothing

Pack the night before when possible. Keep frequently used, inexpensive toiletries in the bag so they do not have to be remembered each time.

## 5. Choose the three versions

| Version | When to use it | Exact plan |
|---|---|---|
| Full | Time and energy are as expected |  |
| Short | The day is compressed but movement is still practical |  |
| Minimum | The original outing cannot happen |  |

The short and minimum versions should be decided before the stressful day. They may be a shorter trainer-approved workout, a walk with someone, mobility practice, or rescheduling into a protected slot. They should fit the participant's goals and current ability.

## 7. Debrief in two minutes

Complete this after the outing:

- What took longer or less time than expected?
- Where did I feel confused or rushed?
- What item did I need but not have?
- What part did I enjoy?
- What needs trainer feedback?
- What one change will make the next outing easier?
- Did the full outing feel worth the total time?

After three visits, use the actual column to set a realistic recurring calendar block.
